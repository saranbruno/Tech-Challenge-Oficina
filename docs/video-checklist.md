# Checklist de gravacao

- Abrir o projeto no navegador.
- Demonstrar `docker compose ps`.
- Mostrar o Swagger funcionando.
- Executar login administrativo.
- Navegar pelos CRUDs principais.
- Criar uma Ordem de Servico.
- Mostrar o orcamento calculado pelo servidor.
- Aprovar a OS pelo fluxo do cliente.
- Mostrar a transicao do status ate entrega.
- Abrir a consulta de tempo medio.
- Rodar os testes principais.
- Mostrar a cobertura real.
- Abrir o relatorio de vulnerabilidades.
- Encerrar com o README e a documentacao DDD.
